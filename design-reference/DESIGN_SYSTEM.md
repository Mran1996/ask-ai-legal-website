## Typography

- Headings: bold, line-height 1.2, clamp for responsive scale
- Body: line-height 1.6, system or sans-serif stack
- Title scale: `clamp(28px, 5vw, 40px)`
- Subtitle scale: `clamp(24px, 4vw, 36px)`

## Spacing

- Section padding desktop: 64px
- Section padding mobile: 32px
- Container padding desktop: 24px
- Container padding mobile: 16px

## Components

### Primary button
- Background `#00A95C`, white text, rounded-md, hover `#059669`

### Outline button (on green hero)
- White background, emerald text/border, hover inverts

### Navigation
- Sticky white header, border-bottom gray-200

### Hero
- Full-width emerald-500 background, white text

- Direct, empowering, for families and self-represented defendants
- Emphasize: court-ready documents, 24/7 access, no hourly billing
- Covers: criminal motions, civil claims, post-conviction filings
